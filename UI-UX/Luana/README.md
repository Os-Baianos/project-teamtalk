# UI-UX / Luana

Telas e referências de design da Luana (contatos, nova conversa e alinhamento das pranchas de conversas).

## Regras

- Os tokens, a barra superior, as cores, as fontes, os botões e os ícones são os mesmos usados em `UI-UX/Gil/`. Não criar versões próprias.
- Mudança em token ou componente comum só entra com o Gil de acordo.
- Seguir as instruções de `UI-UX/README.md` e de `UI-UX/Gil/handoff/`.
