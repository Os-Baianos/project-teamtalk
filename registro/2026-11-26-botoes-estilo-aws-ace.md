# Botões no estilo do console AWS

Quem: Pedro França Leal (Acebmoon)
Data: 2026-11-26

## O que foi feito
- O componente Botao (design-system.module.css) agora é arredondado em pílula, como os botões do console e do Skill Builder da AWS.
- Primário: laranja cheio. Secundário: contorno azul com texto azul. Perigo: contorno vermelho que enche ao passar o mouse.
- Vale para todas as telas, inclusive Painel Dev e o botão Editar do Perfil, para manter um único padrão.

## Ajuste de tamanho
- Botão mais compacto (altura mínima de 2rem), como no console AWS.
- Linha "Nome" do Perfil volta a ter a mesma altura das outras linhas.
