## Pendências e dúvidas
- A branch remota de mesmo nome já estava ligada ao PR #182 em rascunho; este trabalho atualiza esse PR, sem criar duplicata nem fazer merge.
- O push via remote SSH falhou por falta de chave; a branch e o PR foram atualizados pela conexão GitHub da sessão.
- As actions atuais não expõem erros retornados pelo Supabase em consultas; falhas RPC podem aparecer à tela como lista vazia. É necessário que o back-end devolva erros para distinguir os estados.
- Equipes, favoritos, navegação de arquivos e departamentos de avatar não estão disponíveis nos contratos atuais. As abas sem dados estão desativadas e avatares sem foto usam a superfície neutra oficial.
- O contrato atual cobre envio de texto, não compartilhamento de PDF. Nenhum controle de anexo foi inventado.
- O stylesheet de tokens oficial precisa ser importado pelo layout quando a implementação for integrada.
- UI-UX: sem solicitação; os elementos necessários existem nas referências e nos assets atuais.
